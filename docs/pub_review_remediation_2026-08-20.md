- **Major issue 2 / checklist (a): central algebraic equivalence
  was false as coded, not merely unproven.** `[verified]`. While
  building a unit test for the point-estimate identity
  (`inst/tinytest/test_sim_kernels.R`), the original "cell-means"
  MMRM specification (`gls(y ~ 0 + tg, ...)`, contrast
  `mu_11 - mu_10`) was found to reduce algebraically to the raw,
  baseline-unadjusted follow-up group difference for any
  covariance structure (a standard saturated-mean-model /
  Zellner-SUR result), confirmed both by derivation and by direct
  computation (gap of 3.7 vs. ANCOVA's baseline-adjusted estimate
  on a real replication). This was **not** flagged by the original
  whitepaper, which inferred SE near-identity from Table 1 without
  running the code. Fixed by refitting the MMRM as a
  baseline-constrained model (group enters only via a
  post-baseline interaction term, `gls(y ~ time_f + grp_post,
  ...)`), which was verified to reproduce the ANCOVA point estimate
  to `gls` numerical tolerance (< 1e-3) on every replication.
  Files: `R/sim_kernels.R` (`sim_prepost()`),
  `analysis/report/report.Rmd` (Methods "MMRM model", "Extracting
  the treatment contrast", "Algebraic equivalence", Appendix A,
  Discussion Condition 1), `inst/tinytest/test_sim_kernels.R`

## New issues found while fixing

- **The manuscript's headline algebraic-equivalence claim was
  mathematically false for the code as originally written**, not
  merely "asserted, not proved" as the whitepaper characterized it.
  The unconstrained cell-means MMRM contrast reduces to the raw,
  unadjusted follow-up group difference for any covariance
  structure, which does not equal the ANCOVA estimate except under
  baseline balance. This was caught only by writing a real unit
  test with a numerical-identity assertion; the original whitepaper
  review, being non-executing/inspection-based on this point, did
  not surface it. See "Fixed" above for the correction.
- **The Setting 2 "divergence" the original manuscript described
  was an artifact of the DGM/fitted-model mismatch (major issue 4),
  not a real feature of the design.** Once the fitted random-effects
  structure was corrected to match the slope-only DGM, the
  summary-statistic and random-slopes SEs turned out to be nearly
  identical (within 0.6%) across the entire simulated range, rather
  than diverging as `sigma_b/sigma` grows. This is a substantive
  scientific finding, not just a bug fix, and changes the
  paper's Setting 2 narrative; it is reflected honestly in the
  revised Results/Discussion rather than papered over.
- **`analysis/scripts/`, `analysis/tables/`, `analysis/figures/`,
  and `vignettes/` were empty** prior to this remediation pass
  (confirmed by directory listing); `analysis/scripts/` now
  contains `run_simulations.R`. `analysis/tables/` and
  `analysis/figures/` remain empty, since the manuscript embeds
  tables/figures directly via knitr rather than exporting them
  separately; not flagged as an issue by the whitepaper and not
  changed here.
